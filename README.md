# Hero's Burger - Totem e Cardápio Online 🍔

Sistema completo de autoatendimento, gestão de pedidos, PDV e cardápio online desenvolvido em React + Supabase.

## 🚀 Funcionalidades
- **Totem de Autoatendimento:** Interface otimizada para telas touch.
- **Cardápio Online / Mobile:** Pedidos via smartphone com integração via WhatsApp.
- **Painel Admin:** Gestão de produtos, relatórios de vendas, operadores de caixa e configurações.
- **Tela da Cozinha:** Gestão de pedidos em tempo real (Realtime).
- **Fidelidade:** Sistema de pontuação por CPF/Telefone.
- **Caixa/PDV:** Interface para lançamentos manuais no balcão e impressão de cupons via Bluetooth/Térmica.

## 🛠️ Como rodar o projeto
1. Clone o repositório.
2. Instale as dependências com `npm install`.
3. Crie um arquivo `.env` baseado no `.env.example` e insira suas credenciais do Supabase.
4. Rode o projeto com `npm run dev`.
